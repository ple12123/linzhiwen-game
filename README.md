# 林治文 · 第一视角

> 一款 GALGAME 风格视觉小说。运动会、六个项目、一个至今不知道名字的声音。

**在线游玩**：https://ple12123.github.io/linzhiwen-game/

---

## 简介

午后的操场，塑胶跑道被晒得发烫。林治文站在跑道边喘气，忽然做了一个决定——

> 「100米、200米、400米、800米、1000米、2000米——我都报。」

运动会那天，他第一个冲过终点线。欢呼声里，有个声音穿过所有嘈杂落进耳朵：

> 「加油，我看好你哟。」

他左看右看，没有看到人。

## 玩法

- **点击画面 / 空格 / 回车**：推进对话
- **再点一次**：跳过打字机，立即显示全文
- **右上角工具条**：自动播放 · 跳过（快进到下一个选项）· 历史 · 返回标题

| 项目 | 内容 |
|---|---|
| 选择点 | 4 个 |
| 结局 | 3 个（进度保存在浏览器本地） |
| 游玩时长 | 约 10 分钟一周目 |
| 画风 | 二次元 Galgame 截图风格 |

### 结局一览

| 编号 | 名称 | 达成条件 |
|---|---|---|
| **END 01** | 绫 | 告白时选择「好的，小绫」（原稿主线） |
| **END 02** | 一个人的跑道 | 拒绝告白 → 什么也不做，回到跑道 |
| **END 03** | 那个声音 | 拒绝告白 → 追上去 |

> 走到告白那一步时选择拒绝，才会出现第四个选择点。

## 关于本篇

剧本改编自作者的手写稿，分两部分：

- **第一部分**（报名、课间、食堂、起跑前）为手写稿整理，连笔与涂改较多，在保留全部可确认信息与情节顺序的前提下做了通顺化补全
- **第二部分**（枪响 → 3000m → 全金牌 → 告白 → 操场中央）严格照原稿，仅订正错别字，未润色文风；其中 `[Lin]` 即林治文、`[qing]` 即晴钏綾
- **分支与 END 02 / END 03** 为原稿之外新增的原创内容

原稿旁批保留在脚本与游戏中，包括：「我认为这绝对不可能」「完全虚构」「他简直是超人」「写到这没绷住」「真tm猎奇」「那不是嘉豪吗」「没那么低调」「没那么慢」等（红字为原稿旁批，蓝字为补充批注）。

> 设定冷知识：原稿中 3000m 全程速度 30～35 m/s，约为现实短跑世界纪录的三倍——这正是那句旁批的由来。

## 技术

单文件 HTML，无任何外部依赖，CG 以 base64 内嵌。离线双击即可运行。

- 引擎：原生 JavaScript（无框架、无构建）
- 分支：label / goto 跳转表
- 存档：`localStorage` 记录已解锁结局
- 适配：16:9 自适应，移动端竖屏提示横屏

## 本地运行

下载 `index.html`，用浏览器打开即可，无需服务器、无需联网。
